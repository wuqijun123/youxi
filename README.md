# 同词相遇：一直想到同一个词

## 本机运行

使用 Node.js 24。双击“启动游戏.bat”，或在项目目录运行：

```powershell
npm start
```

浏览器打开 `http://localhost:3000`。这个地址仅供本机使用；异地朋友需要访问部署后的公网网址。

## 让异地朋友也能加入

详见同目录的 [公网部署教程.md](公网部署教程.md)，提供 GitHub + Render 的完整操作步骤。

项目没有第三方运行依赖。服务监听 `0.0.0.0`，使用部署平台的 `PORT` 环境变量，本机默认端口 3000；健康检查路径为 `/health`。前端和接口由同一个 Node.js 进程提供。

房间暂存在内存中：服务器重启、更新或平台休眠后，房间与记录会丢失。6 小时没有访问的房间会被清理。当前请只运行一个服务实例/进程；如需多实例或长期保存，需要共享数据库。

## 玩法

1. 两位玩家用邀请链接或房间码进入同一房间。
2. 第一轮各自写一个词，没有题目。
3. 锁定后不能改词；双方都提交后同时揭晓。
4. 如果不同，两人都点击“准备下一轮”后继续各写一个词。可以查看全部历史，联想下一轮。
5. 不限制轮数，直到两人的词相同，立即显示成功和总轮数。
6. 两人都点击“再玩一局”后，清空本局记录，重新开始。

相同判定：忽略首尾空白与英文字母大小写，其余文字须一致；目前不判断同义词。

同一浏览器刷新可恢复身份和记录（前提是服务器里的房间仍然存在）。在一台电脑模拟两位玩家时，请使用两个不同浏览器，或普通窗口与无痕窗口；同一浏览器的两个普通标签页会恢复为同一位玩家。

## 检查

运行 `npm test` 检查双人房间、未揭晓词语的保密、重复提交、并发加入、超过 10 轮、匹配结束、重开和旧请求拦截。
